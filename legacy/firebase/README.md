These files preserve the original `focms-sas-elections-2k25` Firebase identity, connection configuration, rules, and guides for migration reference. The merged application uses the MongoDB/Express backend. These files are not used by the current build.

The complete previous application remains in the first parent of the integration commit. No Firebase data or deployed rules were changed. Follow [MIGRATION.md](../../MIGRATION.md) when preparing a separate MongoDB database.
